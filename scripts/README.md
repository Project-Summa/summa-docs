# Scripts

This directory contains utility scripts for the Summa project.

## Planned Scripts

```text
scripts/
├── README.md
├── check-links.sh       # Validate internal documentation links
├── lint-docs.sh         # Lint markdown files
└── generate-toc.sh      # Generate table of contents for documentation
```

## Usage

Scripts are intended to be run from the repository root:

```bash
./scripts/lint-docs.sh
```

Scripts will be added as documentation tooling needs arise during Phase 0 and Phase 1.
