# Branding

This directory contains branding assets for Summa.

## Contents

```text
branding/
├── README.md
├── logo/            # Logo files (SVG, PNG)
├── icons/           # App icons for each platform
├── colors/          # Brand color palette
└── typography/      # Brand font files
```

## Usage

- `logo/` — Primary and secondary logos in various formats and sizes
- `icons/` — Platform-specific app icons (Android adaptive icons, iOS app icons)
- `colors/` — Source brand color definitions
- `typography/` — Licensed font files used by the brand

See [Design System Documentation](../docs/phase-0/07_DESIGN_SYSTEM.md) for how brand tokens are implemented in code.
