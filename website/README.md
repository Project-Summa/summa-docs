The website is planned for a future phase. This directory serves as a placeholder.

## Technology

The website technology stack has not been decided. Options include:

- Static site generator (Hugo, Astro, etc.)
- Simple HTML/CSS/JS
- Documentation platform (VitePress, MkDocs, etc.)

The website should be simple, fast and privacy-respecting — consistent with Summa's principles.
