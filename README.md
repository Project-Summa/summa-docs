# Summa

> A privacy-first, open-source personal finance platform. Own your data. Track your money. Your way.

---

## What is Summa?

Summa is a local-first personal finance application that works entirely on your device. No cloud required. No data harvesting. No subscriptions needed to access your own financial history.

---

## Principles

- **Local First** — Everything works offline. No internet connection required.
- **User Owns the Data** — Your financial data belongs to you. Export it anytime.
- **Privacy by Default** — No telemetry. No tracking. No analytics.
- **Cloud is Optional** — Sync across devices when you want. Stay offline when you don't.
- **Open Source** — Transparent, auditable, community-driven.

---

## Current Status

Summa is in **Phase 0 — Foundation**. The team is establishing architecture, documentation and development standards before feature implementation begins.

## Project Phases

| Phase | Name | Focus |
|---|---|---|
| 0 | Foundation | Documentation, architecture and development standards |
| 1 | Local First MVP | Android application with local-only financial tracking |
| 2 | Smart Features | OCR, bank import, smart categorization |
| 3 | Self-Hosted Platform | Synchronization server, multi-device support |
| 4 | Summa Cloud | Managed cloud hosting, billing and premium features |
